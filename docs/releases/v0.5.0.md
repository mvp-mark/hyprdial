More languages, every Omarchy shortcut can get a new key, and a ready package to install.

### Install
```bash
sudo pacman -U https://github.com/mvp-mark/omarchy-settings/releases/download/v0.5.0/omarchy-settings-0.5.0-1-any.pkg.tar.zst
```
Or build it with the attached `PKGBUILD` (`makepkg -si`).

### Languages
- **Spanish, French and German**, alongside English and Brazilian Portuguese. They are new and still await a native speaker's review; corrections are welcome.

### Shortcuts
- The shortcuts Omarchy makes in loops (workspaces 1–10, group windows, bar panels) can now get a new key, not only be disabled.

### Bar
- Spacers can repeat: add more than one, and remove one at a time.
