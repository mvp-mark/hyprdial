More languages, every Omarchy shortcut can get a new key, and a ready package to install.

### Install
The package attached to this release was named `omarchy-settings`, the name of a package in Omarchy's own repository, so installing it replaced Omarchy's package. It has been removed; install the package `omarchy-settings-gui` from the [latest release](https://github.com/mvp-mark/omarchy-settings/releases/latest) instead. If you installed it, put Omarchy's package back with `sudo pacman -S omarchy-settings`.

### Languages
- **Spanish, French and German**, alongside English and Brazilian Portuguese. They are new and still await a native speaker's review; corrections are welcome.

### Shortcuts
- The shortcuts Omarchy makes in loops (workspaces 1–10, group windows, bar panels) can now get a new key, not only be disabled.

### Bar
- Spacers can repeat: add more than one, and remove one at a time.
