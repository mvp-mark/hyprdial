Install a language and switch to it in one step, see which version you run, and the app opens without libnm.

### Install
```bash
sudo pacman -U https://github.com/mvp-mark/omarchy-settings/releases/download/v0.6.0/omarchy-settings-gui-0.6.0-1-any.pkg.tar.zst
```
Or build it with the attached `PKGBUILD` (`makepkg -si`).

### System
- **Install and use**: installing a language can also make it the system language as soon as `locale-gen` finishes.
- The language list starts on the one that matches your keyboard layout.
- **About** shows the app's version and where it runs from (package, `install.sh` copy or source folder), warns when it's installed twice with the command to remove the extra copy, and tells you when a newer release is out.

### Fixes
- The app opens without `libnm`; it's needed only to save a Wi-Fi password, and is now listed as an optional dependency.

### Under the hood
- Releases are built and published by GitHub Actions from the tag.
- Every page is opened in a headless smoke test on each push.
