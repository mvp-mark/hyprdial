Install another language from the System page.

### System
- **Install a language**: lists the languages in `/etc/locale.gen` that aren't on the system yet (searchable, named in your language for the common ones). Install opens Omarchy's terminal, asks for your password, enables the language and runs `locale-gen`; it then shows up under System language, ready to apply.

### Install
```bash
sudo pacman -U https://github.com/mvp-mark/omarchy-settings/releases/download/v0.5.2/omarchy-settings-0.5.2-1-any.pkg.tar.zst
```
Or build it with the attached `PKGBUILD` (`makepkg -si`).
