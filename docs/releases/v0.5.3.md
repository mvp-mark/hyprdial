The package is now called **omarchy-settings-gui**.

### Important
Omarchy's own repository has a package named `omarchy-settings` (Omarchy's defaults, fonts and helpers, required by `omarchy`). The packages attached to releases 0.5.0–0.5.2 used that same name, so installing one replaced Omarchy's package. They have been removed from those releases.

If you installed one of them, put Omarchy's package back and install this one:
```bash
sudo pacman -S omarchy-settings
sudo pacman -U https://github.com/mvp-mark/omarchy-settings/releases/download/v0.5.3/omarchy-settings-gui-0.5.3-1-any.pkg.tar.zst
```

The command is still `omarchy-settings`, and the app is the same as 0.5.2 (it includes installing a language from the System page).

### Install
```bash
sudo pacman -U https://github.com/mvp-mark/omarchy-settings/releases/download/v0.5.3/omarchy-settings-gui-0.5.3-1-any.pkg.tar.zst
```
Or build it with the attached `PKGBUILD` (`makepkg -si`).
