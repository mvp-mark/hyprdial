A sidebar like GNOME Settings, grouped like Omarchy's menu, three new pages, and a cleaner codebase.

### Navigation and look
- **Sidebar** in place of the tabs, grouped like Omarchy's menu: Style, Hardware, System. On narrow windows the sidebar and the page take turns.
- The window uses the **current Omarchy theme's accent color**, and follows it when the theme changes.
- **Changed settings** get a bar of the accent color, and **☰ → Changed settings** lists them all.

### Pages
- **Appearance** and **Input** replace the Hyprland page. Input adds touchpad and touchscreen switches when the computer has them.
- **Accessibility** (new): text size, pointer size, animations.
- **Security** (new): fingerprint (with a reader), FIDO2 key and SSH server, set up or removed in a terminal, with the same conditions as Omarchy's menu.
- **Power**: "Suspend in the system menu", and hibernation set up or removed.
- **Bluetooth**: on/off, connect, disconnect and forget go through Omarchy's commands, which also unblock the radio.

### Under the hood
- Pages only build the interface; every command lives in a testable module (`docs/ARCHITECTURE.md` describes the layers and the "Omarchy first" rules).
- Shared widgets for debouncing, confirmations and live refresh.
- ruff lint and formatting in CI, and one shared fake command runner for the tests.

### Packaging
- `packaging/arch/PKGBUILD`, also attached here: `makepkg -si` installs the app system-wide.
