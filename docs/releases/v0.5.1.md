Mouse shortcuts.

### Shortcuts
- Mouse buttons and the wheel show by name: **Super + Right click** instead of `Super + Mouse:273`.
- The key dialog records clicks and scrolls too, so mouse shortcuts can get another button, and any shortcut can go on the mouse.
- Moving and resizing windows only accept a mouse button, and every mouse shortcut needs a modifier, so a change can't break dragging or normal clicking.
- Modifiers picked by hand stay when the recorded key or button comes without any (useful when Hyprland grabs the combination first).

### Install
The package attached to this release was named `omarchy-settings`, the name of a package in Omarchy's own repository, so installing it replaced Omarchy's package. It has been removed; install the package `omarchy-settings-gui` from the [latest release](https://github.com/mvp-mark/omarchy-settings/releases/latest) instead. If you installed it, put Omarchy's package back with `sudo pacman -S omarchy-settings`.
