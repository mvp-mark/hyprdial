Window rules, workspaces, and on plain Hyprland: lock and idle, wallpaper and the bar.

### Install
```bash
sudo pacman -U https://github.com/mvp-mark/hyprdial/releases/download/v1.1.0/hyprdial-1.1.0-1-any.pkg.tar.zst
```
Or build it with the attached `PKGBUILD` (`makepkg -si`), or run `./install.sh --deps` from the source on any supported distribution.

### Everywhere
- **Windows**: a new page for what happens when an app's window opens: float, center, size, workspace (in the background or not), opacity, show on every workspace, fullscreen, maximized, keep the screen on in fullscreen. Pick one of the open windows or type its class; the rules already in your `.lua` files are listed too, read only.
- **Workspaces** on the Displays page: which display shows workspaces 1–10, the one each display starts on, and the ones that always exist.

### Plain Hyprland
- **Lock and idle** on the Power page: when to dim, lock, turn the screen off and suspend, through hypridle (hyprlock as the lock screen).
- **Wallpaper** on the Appearance page: one image or one per display, and how it fits, through hyprpaper, changed live.
- **Bar**: a page that starts Waybar with Hyprland, sets its position and creates neutral starter files.
- hypridle and hyprpaper read their own config format, so Hyprdial writes `~/.config/hypr/hyprdial-idle.conf` and `hyprdial-paper.conf` and starts them with `-c`. A `hypridle.conf` or `hyprpaper.conf` of yours stays in charge.
- New optional dependencies: `hypridle`, `hyprlock`, `hyprpaper`, `brightnessctl` (Fedora has the first three only in third-party repositories).

### Also
- Omarchy's commands count as missing on plain Hyprland, so `HYPRDIAL_PLATFORM=hyprland` on Omarchy shows exactly what a plain Hyprland shows.
- The release workflow no longer stops when it pins the checksum for a tag that isn't the tip of `main`.
