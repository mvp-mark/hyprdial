**omarchy-settings is now Hyprdial**, and it runs on plain Hyprland as well as on Omarchy.

### Install
```bash
sudo pacman -U https://github.com/mvp-mark/hyprdial/releases/download/v1.0.0/hyprdial-1.0.0-1-any.pkg.tar.zst
```
It replaces `omarchy-settings-gui`. Or build it with the attached `PKGBUILD` (`makepkg -si`), or run `./install.sh --deps` from the source on any supported distribution.

### Coming from omarchy-settings
- The first start moves `~/.config/hypr/omarchy-settings.lua` to `hyprdial.lua` and `~/.config/omarchy-settings/` to `~/.config/hyprdial/`, and updates the `require` line in `hyprland.lua`. Nothing else changes in your config.
- The command is `hyprdial`; `omarchy-settings` keeps working.
- `./install.sh` removes a copy installed under the old name.

### Plain Hyprland
- Requires Hyprland 0.56 or newer with `hyprland.lua`. On an older Hyprland, or with a config still in `hyprland.conf`, a notice says so and nothing is written.
- Omarchy-only pages and options (themes, bar, web apps, security, power button, idle times) are hidden.
- Shortcuts are read from the `hl.bind` calls in your `.lua` files and written with `hl.bind`; startup apps with `hl.on("hyprland.start")`.
- Passwords are asked in your terminal (`xdg-terminal-exec`, kitty, foot, alacritty…); the browser default goes through `xdg-mime`.

### Distributions
- Arch and derivatives, Fedora and openSUSE Tumbleweed: **☰ → Dependencies** and `install.sh` use `pacman`, `dnf` or `zypper` with each distribution's package names (Debian's are there too, for when it ships Hyprland 0.56).
- Installing a language uses `locale-gen` on Arch and Debian and a `glibc-langpack` on Fedora.
- CI installs the dependencies by those names on Fedora, Tumbleweed and Debian and runs the tests there.

### Omarchy
- Everything works as before. Texts that said "Omarchy's default" now say "the default".
